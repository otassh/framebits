# Contributing

## Checks

Run from the repo root:

- `pnpm i`
- `pnpm build`
- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`

## Commits

Use conventional commits (e.g. `feat:`, `fix:`, `chore:`). One task = one commit/PR.

## Registry

Never edit files in `registry/components/**` by hand — use the generator (`pnpm new-component`).
